# App Platform prompts

Prompts are bounded task entry points, not architecture authority. Each prompt must link to the
platform documentation required for its task instead of copying requirements, decisions, or
acceptance criteria.

- [Infrastructure-planning handoff](starting_prompt.md) starts a new chat from updated `main` after
  AP-M4 merges. It loads the approved Contract and Fixture boundaries before proposing item 5
  planning and Live-evaluation authority.

The handoff prompt authorizes an item 5 plan and evaluation proposal only. It does not authorize
Terraform, a cloud or DNS mutation, identity configuration, deployment, Application Adoption, or
Live qualification.
