# App Platform prompts

Prompts are bounded task entry points, not architecture authority. Each prompt must link to the
platform documentation required for its task instead of copying requirements, decisions, or
acceptance criteria.

- [System-design handoff](starting_prompt.md) starts a new chat by loading the approved requirements,
  decisions, vocabulary, and repository boundary before proposing the next slice.

The handoff prompt authorizes planning only. It does not create system-design authority or permit
implementation, infrastructure mutation, application migration, or live qualification.
