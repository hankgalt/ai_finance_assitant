# Backend package

FastAPI foundation, versioned contracts, the M1 offline knowledge pipeline, M2 deterministic finance modules, M3 provider ports/adapters, the M4 six-agent LangGraph workflow, and the M4.1 OpenAI ModelAdapter for AI Finance Assistant.

Runtime code performs read-only Qdrant compatibility checks and retrieval. Collection creation, source fetching, embedding, evaluation, activation, and rollback are available only through `python -m ai_finance_assistant.knowledge.cli` and the repository Make targets.

`ai_finance_assistant.finance` exposes the M2 PortfolioImport, PortfolioAnalysis, and GoalProjection interfaces plus the reserved CashFlowAnalysisService contract. These modules have no FastAPI route or persistence adapter yet; M5 owns those interfaces and lifecycle implementations.

`ai_finance_assistant.providers` exposes MarketDataProvider and NewsProvider ports, deterministic credential-free adapters, conditional Alpha Vantage/Massive market adapters, a Tavily news adapter, and explicit bundle factories. Credential-free mode is the default. `AIFA_MARKET_DATA_PROVIDER=alpha_vantage|massive` selects one live market adapter before a workflow; there is no automatic mid-workflow fallback. Live adapters do not call the network until invoked and must pass account-rights, credential, readiness, and budget gates. M4 owns agent consumption and measured provider RunEvents; M5 owns API lifecycle integration.

`ai_finance_assistant.workflow.WorkflowApplication` assembles exactly six specialist agents plus a new selected provider bundle and model adapter for each Run. The compiled graph routes one or more domains, enforces deadline/hop bounds, preserves independent partial results, synthesizes typed output, and checkpoints follow-up routing by Session/Workflow thread. Credential-free mode uses the deterministic adapter. Conditional live mode uses OpenAI `gpt-6.1-sol` through Responses structured output with `store=False`, no tools, bounded retries, and a six-attempt Run budget. The application is an internal M4/M4.1 interface; M5 owns REST/SSE and durable checkpoint/RunEvent adapters.

`ai_finance_assistant.observability` provides disabled, in-memory, and OpenTelemetry modes behind a small interface. RunEvents remain the authoritative product record. OpenTelemetry attributes are allow-listed and exporter failure is isolated. Optional LangSmith tracing is disabled by default and creates a client with inputs and outputs hidden when explicitly enabled. Backend request instrumentation and a Collector/exporter belong to M5; browser telemetry belongs to M6.

The ordinary test suite excludes tests marked `live_provider` and `live_model`. With approved selected-market and Tavily credentials and terms flags in `backend/.env`, `make provider-live-check` explicitly enables two bounded smoke tests: at most three selected-market requests and one Tavily request. With an approved OpenAI key and terms flag, `make model-live-check` makes exactly six calls, one per specialist agent. Restart a running backend after changing an environment-selected adapter. For Massive, individual-plan data must remain owner-only unless Business/commercial display rights cover the demo audience.
